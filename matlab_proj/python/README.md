# Питон-эталоны

`tricanter3.py` — исходная рабочая модель. Источник истины для всей
сверки. **Не править**: любое изменение делает 30 CSV в `ref_dyn/`
недействительными.

## Перегенерация эталонов

```
cd python
python dump_reference_dyn.py     # динамический вариант, §7.2 — актуальный
python dump_reference.py         # квазистатика, §7.1 — справочно
```

Требуется numpy. Скрипт импортирует `tricanter3` как модуль, поэтому
файл обязан лежать рядом. Пишет в `../ref_dyn/`, перезаписывая молча.

## Когда перегенерировать

Только при осознанном изменении параметров — например, когда D закончит
идентификацию `u_conv`. Тогда: запуск скрипта, `git diff` по `ref_dyn/`
(должны измениться ровно ожидаемые файлы), коммит новых CSV целиком.

До этого момента параметры не трогать. Расхождение между `tricanter3.py`
и CSV не даёт никакой диагностики — тесты просто начнут падать у всех
одновременно, и причина будет неочевидна.

## Проверка целостности

Перегенерация на неизменённых параметрах обязана дать побитово те же
файлы. Если `git status` после запуска чист — эталоны и модель
согласованы.
